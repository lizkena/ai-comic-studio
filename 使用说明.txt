AI漫剧工作台 · 独立可修改版

1. 将整个文件夹解压到可写入的位置，双击 AI漫剧工作台.exe 启动。
2. 已内置 Python 和 FFmpeg，无需另装 Python。系统需有 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
3. 此版没有配置任何 API 渠道和密钥，也不含原工作台的作品、素材、任务或浏览器登录信息。首次启动后，在设置中添加自己的 API。
4. 数据保存在此文件夹的 data 目录。可与原工作台同时使用，端口和数据相互独立。
5. app 是后端源码，web 是界面源码，skills 与 skill_modules 是技能。可自由编辑自己这份副本，修改后双击“重启工作台.cmd”加载。
6. launcher.cs 是桌面启动器源码，修改后在 Windows PowerShell 运行“重新编译启动器.ps1”。编译时先关闭这份副本的窗口。
7. 生图、生视频与文字模型需使用你配置的外部服务，费用按服务商计费。未捆绑本地 H3 大模型；如需使用可在程序中另行部署。
8. 分发时请发送完整 ZIP，不能只发送 EXE。

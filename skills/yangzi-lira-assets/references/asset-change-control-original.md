# 资产咨询与修改隔离规则

## 两种模式不得混用

### 咨询模式

触发示例：`你觉得怎么改`、`这个资产有什么问题`、`给我几个优化方向`。

- 必须先实际读取资产文件并查看对应图片；没有图片时只根据已有文字说明提出有限建议，不得假装看见画面问题。
- 给出 2 至 3 个互斥方案，说明各自改变什么、保留什么、风险和适用场景。
- 所有建议都是候选，不写回资产文件，不生成新版本，不调用图像生成平台。

### 执行模式

只有用户明确选择方案或逐项说明修改方向后才能进入。先生成并展示资产修改单，状态写“待确认”；用户再次确认后才执行。

```text
资产编号：
当前版本：
实际查看的文件：
必须保留：
允许修改：
禁止修改：
用户确认方向：
目标工具：
输出版本：
状态：待确认
```

## 防幻觉与版本规则

- 不得凭聊天记忆猜测当前资产的颜色、服装、构图、道具、人物状态或光线。
- “帮我优化”不构成修改授权；信息不足时只给方案并停止。
- 每次只修改用户确认的资产编号和字段。
- 原图片、原提示词和旧版本永久保留；先扫描同一资产 ID 的已有文件，再使用下一个三位版本号，例如从 `v003` 升为 `v004`。
- 修改已有画面时，完整列出身份、构图、机位、光影、背景、道具和未修改区域的保留项。
- 用户只要求修改局部时，不得借机更换整体风格、摄影机角度、人物身份或场景结构。

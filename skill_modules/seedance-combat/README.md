# 打斗动作与运镜 · 使用说明

从用户提供的七份 Seedance 打斗 Excel 整理成专业补充技能。用于拆分镜、镜头静帧提示词和视频提示词整理，不替换编剧、资产规则或制作流程。默认启用；在技能库可停用。

## 如何使用

在原有分镜或整理提示词入口描述当前动作，例如：“两人在仓库搏斗，甲挥拳，乙侧身闪避后退；保留写实风格和既有身份，拆成三个连续镜头。”兵器镜头可说：“整理这一镜的刀剑交锋，写清持剑手、格挡接触与收势，并承接上镜站位。”

自动匹配当前任务中的打斗、挥拳、格挡、武打、交战等词；只加载基础动作和运镜，明确兵器、群战或法术再追加对应参考。它与电影感镜头技能共同提供方法，原阶段技能仍负责输出。若当前提示词没有明显动作词，请在整理要求中说明打斗类型。

1.0.1 补充斧劈、挥斧、劈砍、边打边退／且战且退、拳脚攻防与异兽扑击、撕咬等动作表达。例如“陈野挥斧劈开影牙后撤”会同时加载动作、运镜和兵器参考；只写“拿着消防斧走向地铁口”不会仅因持有兵器触发。更新只影响新建的提示词整理任务，已有任务的技能快照和成品保留；要对旧镜头应用新规则，请重新整理提示词。

直接点击生图或提交已有视频提示词不会额外调用文字模型，先执行整理提示词才能使用此技能。角色卡、身份卡、场景卡的资产生成不会调用它；怪兽和宠物在搏斗镜头中仍引用自己的角色及身份。

任务日志可查看“自动调度专业技能”、模块版本和读取文件。每个新任务固定技能快照；停用只影响后续新任务。

## 对原资料的适配

原表说明与案例对秒数、角度等要求不一致，采用平台当前模型和字段要求；不复制案例的竖屏、仙侠、冷蓝雨夜或多连招默认设定。词库中的“低崩坏”和“官方规范”是原资料说法，未当作经验证的模型性能或官方承诺。

原始 Excel 与完整文本导出保存在 skills/_sources/seedance-combat，供核对；自动调度读取精简适配文档。未执行第三方脚本，未改变渠道、资产布局或生成按钮。词库不等于质量保证，实际动作与衔接需生成后查看。

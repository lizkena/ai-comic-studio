# 打斗动作与运镜

作为当前阶段的专业补充，保留原输出 JSON、角色和身份 ID、素材引用、时长、画幅、项目影像风格。不要另起创作流程、换模型或直接提交媒体生成。

## 把词库变成可执行动作

先明确双方是谁、各自位于哪里、朝向谁、哪只手持哪件兵器、起始距离和障碍。不要把人物摆成面对摄影机接受采访；目光、身体朝向和攻击方向指向对手。

将抽象“激烈打斗”落实为一个短动作单元：起势 → 谁发起什么动作 → 对手怎样防御或闪避 → 实际接触或落空 → 受力反馈 → 结束位置与姿态。只写剧情需要的动作，不堆满词库。短镜头优先一组清楚攻防；复杂连招拆到后续镜头，保留平台时长预算。

写清支撑脚、重心移动、兵器握持及接触先后。接触后才出现受力和环境变化；落空不能同时让对方无因倒飞。避免双方兵器穿过身体、换手或交换所有者。怪兽、宠物按已有体型、关节、四足/翅膀/尾部设计动作，不套人类拳法，不新建道具卡代替角色卡，也不改其声音或身份版本。

## 镜头与连续性

每镜选择一个主要运镜。优先固定、侧向跟拍或轻微手持，保持关键双方和动作接触点可见；贴脸特写不承担完整踢击或全身摔投。过肩镜头是观察位置，不等于第一人称主观视角。复杂环绕、变焦推镜和空中俯冲按实际模型能力谨慎选用。

静帧提示词只描述一个决定性瞬间，不把起势、攻击和倒地拼在一张图中。视频提示词描述动作顺序，时间分段遵守平台字段与当前模型约束，不复制案例默认 9:16、2秒或30秒。保留平台既有多镜号能力；需要拆段时通过原分镜结构处理，不擅自插入 Cut to 或改变剪辑流程。

本镜结尾记录双方屏幕位置、朝向、距离、持物手、兵器状态、伤势、场景损坏和视线；下一镜从这些状态接续。保持轴线和运动方向，有换轴必须有明确空间交代。结束动作仍是自然收势或呼吸，不默认定格。

## 风格与特效

写实真人剧使用现有真实场地、合理光源与材质，击打反馈适度。只有剧情明确存在法术、超能力或飞行时才用相应参考；打斗本身不代表玄幻。碰撞不必冒火花，拳击不默认撞碎石墙。雨、冷蓝色、脏污、光粒、残影、血雾、爆炸和慢动作都不是默认值。

选用 [基础动作](references/actions.md) 与 [运镜选择](references/camera.md)。明确兵器交锋再读 [兵器](references/weapons.md)，多人战斗读 [群战](references/groups.md)，明确超自然动作读 [幻想效果](references/fantasy.md)。案例只作节奏与结构参考，不照搬人物、环境和风格。

整理后检查：身份与引用不变，动作可被拍到，攻防有因果，结束状态能接下一镜，时长容得下动作，风格没有漂移。稳定性约束可简短加入，但不能声称提示词保证生成无穿模、真实或完美衔接；没有看过实际成品不得标记验收通过。

# 幻想动作与特效

仅在剧情明确许可时选取。指定施术者、目标、发生顺序与结束状态，遵守原能力边界。现实格斗不加载这些效果。

- 空中空战动作：踏剑飞行、妖兽背负空战、凌空辗转、空中迂回躲闪、空中对冲、悬空结印、俯冲刺击、高空滑翔突袭
- 蓄力大招动作：双手结印、周身灵气汇聚、兵器震颤发光、地面纹路蔓延、气流盘旋、强光汇聚、能量球体凝聚
- 武侠轻功：踏雪无痕、梯云纵腾空、凌波微步闪避、一苇渡江水面行、壁虎游墙、空中三连踏、借力翻跃
- 兵器碰撞：金属火花、兵刃嗡鸣、剑刃震颤、撞击震波、白光迸发、金属弹开残影
- 法术灵气：淡青剑气、赤红烈焰光刃、冰棱碎片、紫色雷电、金色圣光、黑色魔气、环形冲击波、灵气光粒、浮空符文、冰晶护盾、火焰结界
- 物理破坏：地面崩裂、碎石飞溅、墙体裂纹、石柱断裂、树木拦腰折断、烟尘扬尘、爆炸火光、气流冲击波纹、地面深坑
- 动态残影：高速动作拖影、瞬移黑色残影、气流拖尾、衣摆撕裂碎片、漫天飞布、发丝飞扬
- 受伤氛围：淡红色血雾、伤口渗血、地面血迹、破损铠甲、破碎衣料、皮肤擦伤划痕

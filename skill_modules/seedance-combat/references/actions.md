# 基础动作选择

从起势、进攻、防御、反馈、收势各选必要信息，不整行复制。普通物理进攻可选挥拳、肘击、膝撞、踢击；反馈可选后仰、踉跄后撤、失去平衡、松开持物。

- 防御卸力动作：横刀格挡、侧身滑步闪避、后仰躲击、手臂硬抗、手腕翻转卸力、举盾抵挡、遁术规避、腾空翻越躲闪、侧身翻滚、借力反弹、兵器交叉抵挡
- 擒拿缠斗动作：锁臂擒拿、扣腕反转、扭腰摔击、近身拉扯、肩背过摔、压制锁喉、缠绕束缚、近身缠斗拉扯
- 进攻节奏：快攻三连击、连招无缝衔接、佯攻诱敌、虚晃一招、暴风骤雨般连击、蓄力重击破防、连续突进
- 防御反击：卸力反震、借力打力、格挡后反击、破绽突袭、以退为进、空手入白刃、弹开兵器反手刺
- 对峙试探：兵器相抵角力、绕圈对峙、眼神锁定、蓄势待发、呼吸调整、试探性轻击、气势压迫
- 战术走位：蛇形走位闪避、Z 字突进、背身绕后、贴地滑行、高低位切换、包围圈游走、声东击西
- 冷静状态：精准点刺、从容格挡、计算破绽一击、面无表情斩杀、优雅闪避
- 疲惫状态：动作迟缓、勉强格挡、踉跄反击、靠兵器支撑、咬牙坚持
- 恐惧状态：慌乱后退、盲目挥砍、转身逃跑、颤抖防御、跪地求饶
- 战后状态：拄剑喘息、单膝跪地撑刀、满身伤痕站立、背影远去、收剑入鞘、仰天倒下

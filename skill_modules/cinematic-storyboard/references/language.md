# 摄影层（镜头语法）

写镜头细节、选焦段、定景别与角度时读。输入：镜头账本 + 导演决定书机位签名；输出：逐镜摄影卡（机位/拍向/高度/景别/焦段意图/轴线侧）。导演卡已给出的以卡为准。AI 只认画面内容，不认米数——写可见结果，不写测量值。

## 景别阶梯（6 级）

| 级 | 内容 | 读作 | 失败 |
|---|---|---|---|
| EWS | 人 ≤ 1/8 画高 | 地理、命运、渺小 | 观众 1 秒内找不到主体 |
| WS | 全身 + 环境 | 身体与空间关系 | 需要脸承担节拍时 |
| MS | 腰上 | 可读的动作与对白 | 既不够空间也不够内心 |
| MCU | 胸上 | 表演 + 情境 | 滥用变电视剧 |
| CU | 头肩 | 想法、决断、恐惧 | 角色还没决定就切给脸 = 空白 |
| ECU | 眼/手/物 | 困惑、证据、生理压力 | 地理未建立就用 = 迷失 |

**跳格规则**：同轴换景别必须跳两级（MS→CU 可以，MS→MCU 是口吃）；换角度 ≥30° 才允许跳一级。

AI 边界：模型在 MS–CU 最可靠；EWS 易糊脸、多人；ECU 易融牙、错指数。难镜头往中间带安排，或先出静帧再小动。

## 角度

| 角度 | 读作 | 失败 |
|---|---|---|
| 平视 | 中立、观察 | 场景需要立场时给了中立 |
| 仰拍 | 权威、威胁、神话 | 对象实际弱势 = 滑稽 |
| 俯拍 | 脆弱、审判 | 用在角色强势节拍上 = 拆台 |
| 顶俯 | 制度、命运、图案 | 需要脸时——顶上没有脸 |
| 倾斜 | 不稳、失序 | 一场超过两次 = 失效 |

## 机位高度

高度比角度更便宜地改变意义；先定高度、再定角度，多数时候镜头轴保持水平。

| 镜头轴高度 | 读作 |
|---|---|
| 贴地 | 世界压下来；儿童/动物视点 |
| 膝/腰 | 纪念碑感但不卡通 |
| 胸 | 静默的权力微升 |
| 眼 | 同侪、默认 |
| 高于眼 | 被审视、制度压力 |
| 顶俯 | 图表、系统、命运 |

正反打时机位代表画外那个人——用**对方**的眼高，不是被拍者的；坐姿场景整表下调。

AI 写法：不写「1.2m 高」，写「机位低，桌沿切过画面底部，他身后看得见天花板」。

## 运动

| 运动 | 读作 | 失败 |
|---|---|---|
| 锁定 | 控制、仪式、不安 | 画面内无运动 = 死帧 |
| 缓推 | 压力、领悟 | 推的过程中表演无变化 = 空头支票 |
| 缓拉 | 抛弃、孤立、余波 | 节拍未落就拉 = 提前离场 |
| 摇 | 揭示、扫描、连接 | 5 秒内扫满一框宽会频闪 |
| 跟随 | 行程、追逐、具身 | 机速 ≠ 人速 = 画框喘息 |
| 手持 | 不稳、纪录即时性 | 用在关于控制的戏 = 自相矛盾 |
| 环绕 | 转变、诱惑 | 静态对话上用 = 紧张兮兮 |
| 升降 | 尺度、释放、命运 | 场景没挣到就升 = 廉价 |

一镜一主运动。AI 视频尤其如此，除非工具明示组合控制。

## 焦段决策表（全画幅等效）

| 意图 | 焦段 | 原因 |
|---|---|---|
| 我们在他的恐慌里 | 18–24 贴身手持 | 空间膨胀，房间不稳 |
| 陪伴不审判 | 35–40 | 接近人眼，画面停止表态 |
| 同情、私念、忏悔 | 85 | 脸被善待，背景融化 |
| 被处境困住 | 100–200 | 压缩把背景糊到背上 |
| 被观看/在偷看 | 135–200 躲藏位 | 距离本身即视点 |
| 房间压制人 | 14–24 人小、头顶结构可见 | 建筑成为最大物；别同时压低机位（会重新放大人） |
| 两人不可调和 | 85–135 各单拍不双人 | 压缩单人拒绝同框 |
| 两人真的在一起 | 28–40 双人共享焦点 | 一个平面一个真相 |
| 仪式、秩序 | 24–35 对称居中 | 直线保持直 |

**为什么**：焦距不改透视，**距离**才改。长焦逼你站远→平面堆叠；广角让你贴近→平面飞散。宽 + 人大 = 主导；宽 + 人小 = 渺小。机位不能动时换焦只换裁切，不换心理。

弱：`close-up, shallow DOF, cinematic lens`  
强：`85mm close-up from 1.5m, corridor behind compressed into soft vertical bands, eyes sharp, far wall unreadable`

## 景深算术

- 距离 ×2 → 景深 ×4
- 焦距 ×2 → 景深 ÷4
- 光圈开一档 → 景深 ×0.7

实例：2 米处，24mm f/2 ≈ 0.85m；50mm f/2 ≈ 0.19m；85mm f/2 ≈ 0.07m（小于头深——85 f/2 拍人像，3cm 摇晃丢眼）。表演要自由就收 f/4 或后退。

拉焦 = 没剪的剪：两平面必须同属一个连续念头；起在线上或音上，落在反应前。AI 里把拉焦写成**事件**（「焦点在手，约中点移向门后的人」），不写成镜头属性；先烤进首帧。

bokeh 一词会招来圆形光球：写成因与结果——`shot on 85mm at f/1.8 from 1.5m; eyelashes sharp; bookshelf 4m behind dissolves into soft vertical shapes; no circular highlights`。

# 资产与空间（摄影层）

涉及既有场景、产品、连续机位、比例或轴线时读本文。上游：镜头清单 + 导演决定书机位签名；产出：每镜一张摄影机卡（可站带 / 拍向 / 轴侧 / 必见锚点）。使命是守住用户给定的世界事实，不是替他虚构一套完整三维。轴线细则归 [language.md](language.md)；本文只管资产的角色定位与空间证据，不复述语法。

## 参考图的六种角色

同一张图可以身兼数职。只抽灵感不等于承诺还原资产；多张参考互相矛盾时先亮出冲突，不许私自裁定其中一张为真相。

| 角色 | 锁定 | 放开 |
|---|---|---|
| 灵感 | 用户圈定的构图/配色/手法 | 未要求还原的人、物、情节 |
| 画风 | 媒介、线条、色块、明暗、纹理 | 构图、动作、机位 |
| 人物资产 | 身份、指定造型、体态 | 符合剧情的表情动作 |
| 场景资产 | 可见建筑、门窗、家具、数量、拓扑 | 可行机位与调度 |
| 产品资产 | 轮廓、结构、材质、指定标识 | 有视图依据的角度 |
| 剧情锚帧 | 已确认的事件与状态 | 锚点前后的过渡拍法 |

「照这个房间做分镜」≠ 按通用规则重新发明一间屋子。

## 空间证据三档

```
看得见：画面直接给出的位置、相邻关系、遮挡、固定构造
够得着推：深度区间、可通行带、墙体走向——每条附依据与置信度
不知道：画外背面、暗藏开口、精确尺寸、产品反面
坐标系：以固定墙/门/基准机位为原点；屏幕的左右不等于世界的坐标
轴线：对话/交互/行走的主轴；与建筑自身的对称轴分开记
尺度感：姿态、纵深、脚点、同深度参照物
```

举例：浴室正视图能确认左淋浴、后窗、右台盆，仅此而已——推不出镜头背后还有一扇门。反拍之前先问这个机位能看见什么，别让原来那扇窗在对面的墙上再出场一次。

## 每镜摄影机卡

- 机位可站带、拍向、高度、离主体多远、取景多大
- 站在动作轴的哪一侧；主体的屏幕方位与视线如何映射
- 挑少量足以认出原空间的必见锚点
- 按这个机位：谁在画内、谁在画外、谁被挡住
- 行走路径通不通、手臂够不够得着、门能开到多大、镜头会不会穿模
- 这颗镜头将暴露多少未知区域

单图资产默认只支持同侧的有限角度与景别高度变化。用户点名要大反拍或环绕时：讲清依据缺口，给出补视图或平面图方案；拿不到补充信息，就交付带风险标记的设计，且不得宣称背面已精确还原。也不要悄悄取消用户指定的运镜。

## 轴线与比例

世界的构造是死的，屏幕方位随机位而变。维持屏幕左右一致，并不等于空间就对了。

要换轴：用建立镜头、连续走位或明确的运动方向重新定向。故意失衡时，说明观看目的何在。

## 三人轴线

三人同场不存在一条贯穿全场的轴，只有「此刻在交换的两个人」——主导对。轴线取这两人的连线，第三人挂在游离侧。

- 换主导对即换轴：要么用建立镜重新定向，要么让摄影机跟住人物走位连续越线。硬切换对、直接反打，观众立刻失向。
- 惯用解法：第三人每次进场都带动作（走位、递物、回头），用运动本身交代新轴向。
- 三人同框时按三角形读；有人离场/入场，用脚步声或画外视线提示，不上字幕卡。

## 比例

判断比例看这些：脚和膝的落地、坐姿的支撑点、手与道具的接触、同深度的参照物、前后遮挡关系。拿不同景别下的像素身高当缩放依据是错的。没有实测尺寸就只写相对关系。焦段数字替代不了上述任何一项检查。

镜面/玻璃：现实空间与映像空间分开登记。反射出现异常，只按原剧情的例外处理。

固定的窗、门、产品不随机位被复制或搬动。人物大小结合姿态与地面接触判断，不定死像素。

## 验收

对着成图核对：门窗件数、墙面相邻关系、脚点、道具可达性、遮挡、运动路径。看不清就记无法判断。只有文字方案时，验收对象是设计自洽性——不代表三维还原已经成功。

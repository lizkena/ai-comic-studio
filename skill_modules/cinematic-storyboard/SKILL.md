# 电影感镜头平台适配

本模块依据用户提供的 cinematic-storyboard 文档包适配。只处理当前任务；阶段技能继续负责交付结构，平台负责资产、身份、引用、生成与回填。

用可见摄影决定表达风格：机位站在哪一侧、拍向什么、前中后景关系、主体动作、光源在哪里、光落在哪些材料上。避免形容词堆砌或导演姓名代替真实拍法。

分开保存身份不变量与本镜状态。人物外观、服装版本、场景固定结构、道具外形引用现有资产；位置、持有人、开合、亮灭与损伤变化必须有剧情事件依据。每镜明确起始状态、主事件、结束状态，连接实际镜头证据与下一镜；计划不是观察结论。

静态图只画一瞬间，视频才写动作过程。普通镜头为单幅，角色/身份/场景/道具遵循平台既有视图规则。场景提示词守住实际空间和可行照明，区分室内外干湿，不能把风格或天气扩散到全部材质。

后台只返回调用方要求的JSON或提示词正文，不另输出方案、决定书、渠道推荐、宫格方案或文件包。不要强制默认年代、片基、颗粒、污迹、色名数量或导演风格。没有点名导演就按项目视觉风格和影像设定，不加载导演卡。仅用户要求的局部变化可改动。

所附资料供专业推理使用，不作为最终生图提示词原样发送。模型不能读实际图片时，明确以文字状态为依据，不声称已经看图。生成与验收由平台或实际查看成品的操作方完成。

# 电影感镜头 · 使用说明

## 它负责什么

用于分镜拆分、镜头/场景静态提示词和视频动作提示词。把抽象“电影感”落实为可见机位、空间关系、真实光源、材料颜色、动作起止及镜间状态。作为原阶段技能的补充，不替换已有编剧、资产和制作流程。

## 你怎么使用

保持本技能的自动调度处于启用状态，在作品的分镜或提示词页面执行原有任务即可。在自由画布选中镜头或场景卡整理提示词，或者在视频卡执行“整理提示词”，也会匹配相应模块。

可以这样说：“把这一场拆成三个连续镜头，保留人物和道具状态，写清每镜摄影机位置。”或“整理当前视频提示词，保持真实修理铺空间和人物身份，写明起始动作和结束状态。”

直接点击生图、上传图片或生成已有视频，不会额外调用文字模型；想使用本技能整理现有文本，请先执行整理提示词。这里只提供专业指令，实际生成仍由平台当前配置的渠道完成。

## 智能体什么时候加载

- 分镜拆分：story.md + space.md。
- 镜头静帧提示词：space.md + language.md + lighting.md。
- 场景提示词：space.md + lighting.md。
- 视频提示词：space.md + video.md。
- 角色卡、身份卡：不自动调用这个模块，继续使用角色资产规则。

调用记录见任务的执行日志，包含模块名、匹配原因、版本和所读文档。每个新任务固定内容快照；停用影响后续新任务，正在运行或重试的任务保留提交时版本。

## 与平台规则的关系

用户剧情事实、项目视觉风格和影像设定、卡片用途、角色/身份/场景/道具的多视图布局，以及平台输出格式优先。普通镜头仍是单幅画面，不能把参考资产拼版当镜头。无需每次指定导演，也不强行套年代、颗粒、脏污或默认滤镜。没有实际看过图片或视频就不能声称已验收。
